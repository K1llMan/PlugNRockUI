# Plug'n'Rock UI [WIP]

UI for Plug'n'Rock Guitar Host. Based on [RS_CDLCPlayer](https://github.com/CyanIC64/RS_CDLCPlayer) by [CyanIC64](https://github.com/CyanIC64). Rewritten on React/Typescript.

## Features
* All from original player.
* Redesign. 
* Localizations support.
* Keyboard shortcuts in 'VS Code'-style.
* More to go...
